# 📊 看看 | A股盘后情报站

> 实时行情 · 资金流向 · K线图 · 技术指标 · 黄金行情 · 智能买卖建议
>
> 一个自包含的纯前端股票看板，无需后端，开箱即用。

## 🚀 快速开始

### 方式一：直接使用

1. 下载 `index.html`
2. 用浏览器打开即可，数据实时获取

### 方式二：部署到 GitHub Pages

```bash
# 1. 创建仓库
# 2. 上传 index.html
git add index.html
git commit -m "init: 看看盘后情报站"
git push

# 3. 开启 GitHub Pages
# Settings → Pages → Source: main / root → Save
```

### 方式三：Netlify Drop

1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)
2. 拖入 `index.html`
3. 获取即时分享链接

## 🔧 技术架构

```
┌─────────────────────────────────────────┐
│           单文件 HTML 应用               │
│  ┌─────────────────────────────────┐    │
│  │  HTML + CSS + Vanilla JS        │    │
│  │  无框架依赖 · 无构建步骤         │    │
│  └─────────────────────────────────┘    │
│  ┌─────────────────────────────────┐    │
│  │  数据源（JSONP，绕过 CORS）      │    │
│  │  ├ 腾讯行情 API（实时价格）      │    │
│  │  ├ 腾讯 K线 API（走势数据）      │    │
│  │  ├ 东方财富 API（资金流向）      │    │
│  │  └ 东方财富搜索（股票检索）      │    │
│  └─────────────────────────────────┘    │
│  ┌─────────────────────────────────┐    │
│  │  本地存储（localStorage）       │    │
│  │  ├ 自选股票列表                  │    │
│  │  ├ 卡片排序顺序                  │    │
│  │  └ 主题偏好                      │    │
│  └─────────────────────────────────┘    │
└─────────────────────────────────────────┘
```

- **零后端**：所有数据在浏览器端通过 JSONP 实时获取
- **零依赖**：纯 HTML/CSS/JS，无 npm、无打包
- **零配置**：上传即用，无需环境变量或数据库
- **CORS-free**：使用 JSONP (script 标签注入)，完美适配 GitHub Pages / Netlify

## 🎯 核心特性详解

### 实时行情
- 股票价格、涨跌幅、成交量、最高/最低价
- K线图（前复权，30日走势）
- 5秒自动刷新

### 资金流向
- 主力净流入：今日 / 5日 / 10日 / 20日
- SVG 柱状图可视化对比
- 数据源降级：API 失败时从 K 线估算

### 智能买卖建议
- **支撑位**：MA20 或近期低点（取较低者）
- **阻力位**：近期高点或 MA20（取较高者）
- **买入价** = 支撑 × 0.98（下浮2%）
- **卖出价** = 阻力 × 1.02（上浮2%）
- 严格保证：买入价 < 现价 < 卖出价

### 自选管理
- 搜索股票名称或代码
- 一键添加/删除
- 拖拽排序（桌面 HTML5 拖拽 / 移动端 Touch 事件）
- 数据本地持久化，每人独立
